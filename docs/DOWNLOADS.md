## Primeira instalação

1. Toque em **Baixar para Android**.
2. Aguarde o download e abra o arquivo `Valorum-<versão>.apk` no navegador ou na pasta Downloads.
3. Se solicitado, permita que esse navegador instale o aplicativo e confirme a instalação no Android. Você pode revogar essa permissão depois.

Na página de lançamentos, o arquivo certo está em **Assets** e termina em **`.apk`**. Os itens **Source code (zip)** e **Source code (tar.gz)** são arquivos automáticos do GitHub e não instalam o Valorum.

## Atualização de quem já usa

Faça um backup `.valorum` protegido por senha e instale o novo APK por cima da versão existente, **sem desinstalar**. No app, você também pode abrir **Mais ferramentas → Verificar atualizações**. O Android pedirá confirmação para instalar.

Se surgir uma mensagem de conflito de pacote ou de assinatura, não desinstale como primeira tentativa: preserve seus dados e [entre em contato com o suporte](mailto:pc.valorum@gmail.com).
