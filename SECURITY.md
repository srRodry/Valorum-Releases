# Segurança

Este repositório contém arquivos de distribuição do Valorum, não o código-fonte do aplicativo.

Para reportar uma possível vulnerabilidade, **não abra uma Issue pública com detalhes de exploração, credenciais, dados financeiros pessoais ou arquivos de backup**. Utilize o canal de relato privado de vulnerabilidades do GitHub, caso esteja disponível para este repositório, ou entre em contato pelo canal oficial de suporte divulgado no aplicativo.

Para problemas comuns de instalação ou interface, utilize as Issues e compartilhe apenas a versão do Valorum, a versão do Android, o modelo do dispositivo e uma descrição que não exponha informações sensíveis.

Os APKs oficiais são identificados por versão e hash SHA-256 nos arquivos de cada Release. Nunca instale APKs de fontes desconhecidas que usem o nome Valorum.
